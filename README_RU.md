# Jenya VPN

Это настоящий Flutter-клиент VPN, а не HTML-прототип. Он использует sing-box как сетевое ядро и Android VpnService через пакет `sing_box`.

## Что уже есть

- настоящий VPN/TUN через sing-box;
- VLESS, VMess, Trojan, Shadowsocks, Hysteria/Hysteria2, TUIC, WireGuard и другие форматы, которые поддерживает ядро;
- импорт ссылки;
- импорт sing-box JSON;
- импорт файла;
- импорт QR;
- сохранение нескольких конфигураций;
- выбор активной конфигурации;
- подключение/отключение;
- скорость загрузки/отдачи;
- общий трафик;
- длительность сессии;
- тёмный Material 3 интерфейс;
- экран настроек;
- обработка ошибок запуска.

## Важно

Приложение не является VPN-провайдером и не содержит собственных серверов. Пользователь добавляет свою конфигурацию/подписку.

## Сборка Android

1. Установить Flutter 3.44+ и Android Studio.
2. В папке проекта выполнить:
   `flutter pub get`
3. Подключить Android-смартфон с включённой отладкой USB или открыть эмулятор.
4. Выполнить:
   `flutter run`
5. Для APK:
   `flutter build apk --release`
6. APK будет здесь:
   `build/app/outputs/flutter-apk/app-release.apk`

Для Google Play лучше:
`flutter build appbundle --release`

## Первый запуск

Android покажет системный запрос VPN. Нажми «Разрешить».

## Как добавить конфиг

Открой «Добавить» и вставь:
- VLESS/VMess/Trojan/SS/Hysteria2/TUIC/WireGuard ссылку;
- ссылку подписки;
- готовый sing-box JSON;
- файл;
- QR-код.

## Что можно добавить во v2
